## 新报告如何选择格式

用户指定模板时继承该模板。未指定时，优先参考同课程、同类型样本；需要另建统一版式时，将其说明为建议方案。保持清楚的标题层级和图文对应，具体字号、纸型、边距及表格颜色依据当前任务选择。

截图先保证可读性，再按版心设置显示尺寸。保留原图像素和关键参数，宽图可按需要使用横版页面。新稿的实际分页和图表效果在交付时另行检查，结构检查不能代替页面查看。

## 不作为模仿目标的内容

旧样本中的截图文件名式图题、临时备注、章节编号错序、相邻重复解释和大段无意义空白属于编辑问题。它们不代表应当保留的个人偏好。

历史报告中的技术结果和“测试通过”是对应旧实验的陈述。风格归纳没有重新运行这些 GIS、统计、WebGIS 或 C++ 实验；新报告仍须使用本次证据。
