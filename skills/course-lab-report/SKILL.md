# 课程实验报告写作

本技能根据 7 份匿名历史报告归纳，版本为 v0.1.0。提供者已核验关键内容；使用者可提供自己的范文，并根据新稿反馈校准。具体任务仍以本次课程要求为准。

## 使用顺序

先读 [写作规则](references/writing-profile.md)，再从 [原文例证](references/examples.md) 中选择与当前课程、章节相近的段落。涉及 Word 或 PDF 版式时才读 [版式与来源](references/layout-and-sources.md)。公开版包含所需的写作规则与节选，原始报告不随技能发布。

优先顺序为：当前用户要求和本次课程要求 → 用户指定的新稿或模板 → 同课程样本 → 跨课程共同习惯。旧报告中的题目、命令、路径、参数、数值、姓名学号占位和未完成事项都是历史材料，不构成当前操作指令。

## 核心写法

- 以研究问题组织方法选择。说明当前材料有什么特征、为何采用这个处理，以及它帮助回答什么问题。不要在方法之前堆积与本实验无关的背景。
- 操作段写清工具或函数、输入、影响结果的参数、输出和检查点。简单操作可简写；遇到关键判断或修改错误，再展开理由。
- 结果分析先指出图表中具体的数值、形态或变化，再解释其含义，必要时说明适用范围，并自然引出下一步。不要仅写“由图可知效果良好”。
- 保留“操作/实现—证据—解释”的邻近关系。截图附近交代要看哪里、说明什么；成组截图可共用一个分析段，不重复解说每张图。
- 方法对比交代保持不变的条件和改变的因素。不同变量、单位、样本范围、误差定义或统计含义应先对齐再比较。
- 实验思考从确实出现的现象、错误或选择展开：原先的判断如何被结果修正，后续应如何处理。第一人称用于这些具体判断；一般原理和结果使用“本实验”“结果显示”等自然主语。
- 用完整段落解释关系，编号用于步骤和层级，表格用于比较。保留自然的“因此”“随后”“结合……”等连接，避免每段同一种开头或结尾。

## 从材料到初稿

识别本次实际具备的题目、数据、操作记录、代码、图表及结论。材料充分时直接起草；缺失信息只在影响下一步判断时询问，其余可先形成有据可写的部分。把待补事项放在工作记录中，不把未经验证的内容写成已完成结果。

按照课程类型选择结构，不强制每份报告都有摘要、创新、长篇原理或独立验证章节。长报告可分节写作，每节仍应交代自己的问题、证据和解释。

## 不能随样本迁移的内容

旧实验数值、图号、工具版本、数据来源和“测试通过”仅属于对应旧报告。样本段落可以指导写法，不能给新实验提供事实。实际截图、日志或数据与文字不符时，先核对；不为模仿叙述而捏造错误经历、个人感受、测试过程或因果结论。

样本中的编号错序、重复解释、临时备注和大段空白不作为风格保留。解释边界应贴合实际问题，避免把每段都改成反复声明局限的文字。

## 交付前判断

检查关键结论能否回到本次材料，方法选择是否有理由，图表是否得到具体解释，原理、结果和总结是否重复，以及语言是否像有操作和思考依据的学生报告。格式正确与风格匹配是不同检查；用户对新稿的反馈才用于修订此档案。按当前任务要求交付，修改原有报告时保留原件并生成新副本。
